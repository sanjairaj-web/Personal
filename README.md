# Sanjai Raja — Chartered Accountant

Single-page business website for a Chartered Accountant practice based in
Sankagiri, Tamil Nadu.

## Contents
- `index.html` — the full site (self-contained, no build step)

## Usage
Open `index.html` directly in a browser, or deploy the folder as-is to any
static host (GitHub Pages, Vercel, Netlify).
